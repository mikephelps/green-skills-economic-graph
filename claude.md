# Project: Interactive Economic Graph Globe
- **Tech Stack:** Vite + Vanilla JavaScript (or React Three Fiber if preferred), Three.js, Tailwind CSS.
- **Styling Guide:** Minimal dark UI matching the uploaded reference image (#0b0c10 dashboard aesthetic).
- **Architecture:** Keep logic modular. Separate the 3D Globe rendering loop from the UI overlay and data-fetching logic.
- **Data Source:** Use the structured `data.json` file containing geographic coordinates and country/city metrics.
